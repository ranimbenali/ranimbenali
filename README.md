## Featured Projects

### 🎙️ [Speech Emotion Recognition](https://github.com/ranimbenali/Speech-Emotion-Recognition)
**Deep Learning | Audio | Diffusion Models | ResNet-50**

Recognizes emotions from speech using **mel-spectrograms** and a **ResNet-50** backbone adapted to single-channel audio.
A **diffusion model** is used to **generate enhanced emotional speech data**, addressing the lack of high-quality emotional datasets and improving emotion clarity.

> 🔧 *Tech stack:* Python, PyTorch, Torchaudio, Librosa, NumPy, Matplotlib, Kaggle

---

### 🛠️ [GMAO — AI-Powered Maintenance Management](https://github.com/ranimbenali/GMAO)
**Full-Stack | NestJS | Angular | CI/CD**

A **Computerized Maintenance Management System (CMMS)** for managing **equipment, maintenance tasks, scheduling and reports**, with **multi-company** support and role-based access.
Includes an **AI assistant** (OpenAI API) and an automated **Jenkins CI/CD pipeline**.

> 🔧 *Tech stack:* NestJS, Angular 20, Angular Material, MongoDB, JWT, OpenAI API, Jenkins

---

### 📉 [Telecom Churn Prediction — MLOps](https://github.com/ranimbenali/Mlops)
**Machine Learning | MLOps | Random Forest**

Modular ML pipeline predicting **customer churn**: data preparation, training, evaluation and model saving, automated with a **Makefile** and code-quality checks.

> 🔧 *Tech stack:* Python, Scikit-learn, Pandas, MLflow, FastAPI, Joblib, Black, Flake8

---

### 🎮 [2D Adventure Game in C](https://github.com/ranimbenali/Jeu_SDL)
**Game Development | C | SDL**

A 2D game built in **C with SDL**: scrolling backgrounds, collision detection, minimap, animated characters and **timed riddles (enigmas)**, with sound and music.
