## ⭐ Featured Projects

### 🎫 [Helpdesk IA — AI-Powered Support Ticket Platform](https://github.com/ranimbenali/helpdesk-ai-platform)
**End-of-Studies Project (PFE) @ GEISER | NLP | LLM & RAG | Predictive Analytics | MLOps**

A production-ready platform that automates the full life cycle of IT support tickets: **intake, classification, prioritization, routing and follow-up**.
- **Hybrid NLP classification** (category, sub-category, priority): TF-IDF + LinearSVC / XGBoost (**97% accuracy on priority**), with an **LLM fallback** under a confidence threshold, plus **OCR** on attachments
- **Automatic routing** to the most relevant agent based on expertise scoring
- **RAG assistant** (ChromaDB) retrieving similar resolved tickets + **agentic chatbot** performing real actions through tool calling
- **Predictive analytics**: SLA breach risk, anomaly detection, topic clustering, volume forecasting (Prophet)
- **MLOps**: MLflow tracking & model registry driving production serving; Elasticsearch/Kibana monitoring

> 🔧 *Tech stack:* Python, FastAPI, scikit-learn, XGBoost, Groq LLM, ChromaDB, MLflow, PostgreSQL, React, Docker, Elasticsearch, Kibana
